# Contributing to coolify-cli

First off, thank you for considering contributing to coolify-cli! It's people like you that make the open source community such a great place to learn, inspire, and create.

## How to Contribute

### 1. Fork and Clone
- Fork the repository on GitHub.
- Clone your fork locally: `git clone https://github.com/your-username/coolify-cli.git`
- Create a new branch for your feature or bugfix: `git checkout -b feature/your-feature-name`

### 2. Development Requirements
- **.NET 10.0 SDK**: Ensure you have the .NET 10.0 SDK installed on your machine.

### 3. Running Tests
- Before submitting your pull request, ensure all tests pass.
- Run tests using the .NET CLI: `dotnet test`

### 4. Submitting a Pull Request
- Commit your changes with clear, descriptive commit messages.
- Push your branch to your fork: `git push origin feature/your-feature-name`
- Open a Pull Request against the main repository.
- Provide a clear description of the problem you are solving and the changes you have made.

## Code Style and Conventions
- **Follow Existing Conventions**: Please try to match the code style of the existing project.
- **XML Documentation**: Provide XML documentation comments for public classes, methods, and properties.
- **Author Headers**: **KEEP ALL author headers - DO NOT remove them**. If editing an existing file with an author header, leave it intact.

## Reporting Issues
- Use GitHub Issues to report bugs or suggest new features.
- When reporting a bug, please include clear reproduction steps, expected behavior, and actual behavior.
