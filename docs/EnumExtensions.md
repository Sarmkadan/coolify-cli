# EnumExtensions

`EnumExtensions` is a static utility class providing a comprehensive set of extension methods for working with C# enumerations (`enum`). It facilitates common operations such as parsing, formatting, attribute retrieval, flag checking, and conversion between enum values and their string representations or numeric equivalents. The class is designed to reduce boilerplate code when dealing with enums in scenarios like CLI tools, configuration parsing, or user-facing display strings.
